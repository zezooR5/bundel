# Al Badry Trade & UGREEN - Promotional Bundle Image Generator

تطبيق ويب حديث وسريع جداً مخصص لإنشاء صور وبنرات العروض الترويجية للباقات (Bundle Promotions) لشركة **البدري تريد (Al Badry Trade)** وموزعي منتجات **UGREEN** في مصر والشرق الأوسط.

---

## 🚀 المميزات الرئيسية (Core Features)

1. **دقة وضوح فائقة للتصدير (High-DPI Ultra HD)**:
   - تصدير بصيغة **PNG** و **JPG** بأعلى جودة نقاء (2x Ultra HD حتى 2160px و 3x Print حتى 3240px) لتناسب واتساب وفيسبوك وإنستغرام بدون أي تشويش.
   - زر **نسخ لواتساب (Copy to Clipboard)** للصق الصورة مباشرة في محادثات واتساب ويب بضغطة زر.

2. **الشعارات الأصلية مفرغة وبارزة**:
   - شعار **البدري تريد (Al Badry Trade)** وشعار **UGREEN** مفرغان من الخلفية البيضاء وبحجم كبير وفخم.
   - علامة مائية (هامش) أنيقة لشعار البدري تريد في خلفية الكارت الترويجي.

3. **حسابات مالية دقيقة وتلقائية 100%**:
   - حساب إجمالي السعر الأصلي.
   - حساب إجمالي سعر الباقة للقطعة وللكمية الإجمالية.
   - حساب إجمالي التوفير للعميل ونسبة الخصم المئوية (مثل: 26.2% OFF).
   - إمكانية تحديد سعر إجمالي مخصص للباقة يدوياً أو تركه ليحسب تلقائياً.

4. **إطار أخضر فخم وقوالب متعددة**:
   - **القالب الأبيض بإطار أخضر يوجرين الرسمي (16px Border)**.
   - **قالب Dark Tech داكن مع توهج نيون أخضر**.
   - **قالب Strong Promo Offer مع شريط MEGA OFFER وشارات الخصم**.
   - **قالب B2B Wholesale Catalog مع أكواد SKU والكميات**.

5. **3 مقاسات تصدير معتمدة**:
   - **مربع 1:1 (1080 × 1080 px)**: واتساب وفيسبوك وإنستغرام بوست.
   - **طولي 4:5 (1080 × 1350 px)**: إنستغرام فيد.
   - **ستوري 9:16 (1080 × 1920 px)**: حالات واتساب وستوري إنستغرام.

6. **إدارة المنتجات وحفظ الباقات**:
   - إضافة وحذف وإعادة ترتيب المنتجات.
   - رفع صور المنتجات بالسحب والإفلات (Drag & Drop) أو من الكتالوج الجاهز.
   - حفظ وتكرار وتعديل وحذف الباقات محلياً في المتصفح (LocalStorage).
   - واجهة مستخدم ثنائية اللغة (عربي / English).

## 💻 التثبيت والتشغيل المحلي (Setup & Run)

```bash
# تثبيت الحزم
npm install

# تشغيل خادم التطوير
npm run dev

# بناء النسخة الإنتاجية
npm run build
```

## 🛠️ التقنيات المستخدمة (Tech Stack)

- **React 18** + **TypeScript**
- **Vite** (فائق السرعة)
- **Tailwind CSS** (تصميم عصري متجاوب)
- **html-to-image** + **canvas** (محرك تصدير الصور عالي الدقة)
- **Lucide Icons**
